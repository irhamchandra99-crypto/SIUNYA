# SIUNYA
SIUNYA adalah platform digital terpadu mahasiswa Universitas Negeri Yogyakarta untuk mengakses informasi, fasilitas, dan kegiatan kampus. Lewat satu pintu, mahasiswa dapat melaporkan masalah fasilitas dengan fitur pelacakan status secara terstruktur serta mengelola barang hilang (Lost &amp; Found) secara efisien dan transparan.
